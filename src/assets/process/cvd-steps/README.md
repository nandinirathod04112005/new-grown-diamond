# CVD process plates

Drop the twelve step images here. The section discovers them by the NUMBER in
the filename, so any of these work:

    01.webp        cvd-step-01.jpg        step-1.png

`.webp`, `.jpg`, `.jpeg` and `.png` are all accepted. A step with no file still
renders — its number, heading, description and checklist are real text in
`cvdSteps.js`; only the picture is missing.

Save as WebP if you can: these plates are large, and a PNG renamed to `.webp`
is still a PNG. See `SizeGuide` history for what that costs.
